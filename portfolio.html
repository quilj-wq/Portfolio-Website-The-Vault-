Part 2: Design

1. What overall style will best represent you?

The overall style is creative and personal. The website is designed to look like a digital archive or collection rather than a traditional corporate portfolio.

2. What color scheme will you use and why?

The site uses a purple, pink, and white color scheme. Dark purple is used for borders, navigation, buttons, and popup window headers. Light pink is used for the main content areas and popup interiors. A moving purple checkerboard pattern is used in the background. These colors give the website a recognizable and consistent visual identity.

3. What fonts will you use for headings and body text?

The website currently uses Arial for both headings and body text. This keeps the text simple, readable, and consistent across every page.

4. How will your design reflect your personality or field?

The design reflects my interests by combining web development with a creative digital archive concept. The Vault gives each project its own place while still keeping the entire portfolio visually connected.

5. What layout will your homepage follow?

The homepage uses a centered content frame with a large banner at the top, navigation underneath, and the main content below. The content is contained inside a bordered central section while the animated checkerboard background remains visible around it.

6. How will you organize project sections visually?

Projects are organized into clear sections with images or covers on the left and information on the right. Horizontal lines separate entries, and interactive projects can open inside custom popup windows.

7. Will the site be mobile-friendly? How will you ensure responsiveness?

Yes. The website uses CSS media queries to adjust the layout for smaller screens. On mobile devices, content that normally appears side by side changes to a stacked layout. Images, navigation buttons, popup windows, and text sizes are also adjusted for smaller screens.

8. What visual hierarchy will guide visitors?

The main banner establishes the name of the website first. The navigation bar provides access to each major section. Page headings identify the current section, followed by individual entries with larger titles, images, information, and descriptions.

9. How will consistency be maintained across pages?

All pages share the same banner, navigation bar, color palette, borders, fonts, background, content width, and overall layout. This keeps the portfolio visually consistent even though each section demonstrates a different type of project.

10. How will accessibility be considered?

Accessibility is considered through readable font sizes, strong contrast between text and backgrounds, alternative text on images, clearly labeled buttons, responsive layouts, and keyboard controls for some interactive elements.

11. Will you use icons, images, or illustrations? Why?

Yes. The website uses a custom Vault logo, artwork images, book covers, game box art, and other images. Images are important because The Vault is designed to act as a visual archive and portfolio.

12. What portfolio websites inspired your design?

The design is mainly inspired by older desktop interfaces, digital archives, personal websites, and collection-based websites. The draggable popup windows also take inspiration from traditional computer desktop windows.

Part 3: Interactivity

1. What interactive elements will your site include?

The site includes navigation buttons, clickable artwork, clickable book covers, clickable game box art, popup windows, close buttons, fullscreen buttons, restore buttons, draggable windows, book page navigation buttons, keyboard controls, Play buttons, and a custom scrollbar.

2. Will your site include a contact form? How will it work?

A contact form is not currently included. The main focus of the site is the interactive portfolio. A contact page or contact form could be added later if necessary.

3. What JavaScript features will you implement?

JavaScript is used for several features, including:

  • Opening and closing popup windows
  • Dragging popup windows around the screen
  • Switching between fullscreen and normal window sizes
  • Navigating through book pages
  • Tracking the current book page
  • Disabling book navigation buttons when necessary
  • Closing windows with the Escape key
  • Keyboard navigation through book pages
  • Updating the custom scrollbar
  • Opening selected games in popup windows
  • Displaying game box art and Play controls
  • Preparing the Games section for possible browser-based NES emulation

4. How will users receive feedback from interactions?

Buttons change appearance when hovered over or disabled. Popup windows immediately appear when an item is selected. Book page numbers update when pages are changed. Navigation tabs visually show which page is currently active. Game selections open in their own popup window with a clearly visible Play button.

5. How does interactivity improve the user experience?

Interactivity allows visitors to experience the projects instead of only reading about them. Users can open artwork, read books page by page, move popup windows, explore different sections, and interact with game interfaces. This makes the website more engaging and helps demonstrate my programming and design skills through working features instead of only descriptions.
